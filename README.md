## ✨ Unique Animated & Interactive Features

1. **⚡ Live In-Browser Simulation Sandboxes**:
   - **LADRIS Simulator**: Slide parcel area, clearance status, litigation level, and compensation variance to watch real-time LightGBM inference predict delay probability + SHAP feature attribution bar charts!
   - **LearnSphere AI Tutor**: Interactive GenAI assistant with preset prompts and streaming answers.
   - **VidyaQuest STEM Multilingual PWA**: Real-time 8-language switcher (Hindi, Telugu, Tamil, Kannada, Marathi, Bengali, Gujarati, English), offline/online sync simulator, and interactive STEM quiz challenge with XP scoring!
2. **⌘ Command Palette (Ctrl + K / ⌘K)**:
   - Mac/Raycast-style fast search to jump to any section, copy email in 1 click, or launch sandboxes.
3. **🔊 Web Audio API Synthesizer**:
   - Subtle, high-tech micro-click audio feedback (zero external audio files; toggleable in the header).
4. **🌌 Kinetic Constellation Canvas**:
   - Dynamic canvas particle system with distance connections reactive to mouse movement and dark/light modes.
5. **🎛️ Interactive 3D IDE Card**:
   - Live code inspector with tabs (`sathvika.ts` / `skills.json`), 3D gyroscope tilt, and a live "▶ Run" code execution button with terminal output.
6. **🌓 Dual Obsidian / Crisp Light Themes**:
   - Smooth theme transition with high-contrast accessibility compliant with WCAG AA.
