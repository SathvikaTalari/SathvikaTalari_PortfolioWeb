## ✨ Portfolio Key Features

- **🌓 Dual Theme System**:
  - **Dark Mode (Default)**: Sophisticated *Obsidian Nebula* theme (`#090d16`) with electric sky blue (`#38bdf8`) and iris indigo (`#818cf8`) accents.

  - Test simulated project features directly inside modal case studies (AI Tutor prompts, dynamic hotel booking pricing calculator, DFA transition simulator, and emergency broadcast dispatch).
- **🏷️ Authentic Language & Tech Logos**:
  - Integrated brand icons via Devicon (Python, Java, JavaScript, C, C++, Flask, React, HTML5, CSS3, Bootstrap, Git, GitHub, MySQL, SQLite, VS Code).

- **♿ Accessibility (a11y)**:
  - Accessible skip link (`#main-content`), ARIA live regions, focus indicators, and semantic HTML5 elements.

## 💻 How to Run Locally

You can run this portfolio on any computer in seconds without installing complex build tools:

### Option 1: Quick Launch (No installation required)
1. Download or clone this repository.
2. Double-click **`index.html`** to open it in your web browser (Chrome, Edge, Firefox, or Safari).
3. All dependencies (Bootstrap 5, fonts, and styles) work immediately offline.

### Option 2: Run with a Local Server (Recommended for development)
If you have Python installed:
```bash
# Navigate to the project directory
cd personal-portfolio

# Start a local HTTP server
python -m http.server 8080
```
Then open **`http://localhost:8080`** in your browser.
